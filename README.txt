University Timetable Planner

Upload index.html and .nojekyll to the root of your GitHub repository, replacing the old index.html, then commit changes. GitHub Pages should use branch main and folder /(root).

New feature: Select a weekday and week date, then use “Mark cancelled today” on a class to mark that specific occurrence as cancelled. Use “Undo cancellation” to reverse it. Cancellation dates are stored in that browser and included in JSON backups.
